## Program 1: Custom Constants & Math Library (#define & Header Simulation)
####  Concept: Lecture 10 highlights using preprocessor directives (#define) and standard math headers (<cmath>) to define universal constants and call built-in math functions without re-inventing basic mathematical operations.

## Program 2: Variable Scope & Visibility (Global, Local, and Block Scope)
#### Concept: Demonstrates how variables behave across File/Global Scope, Function Scope, and Block Scope ({ }), illustrating why the instructor advises minimizing global variables to prevent unintended side-effects.

## Program 3: Call by Value vs. Call by Reference
####Concept: Contrasts default Call by Value (passing copies so original caller variables remain untouched) with Call by Reference (passing variable addresses/aliases so function modifications directly alter caller variables).

## Program 4: Recursive Functions & Base Case Execution Trace
#### Concept: Demonstrates self-referential functions (Recursion). Highlights the critical requirement of a Base Case to prevent stack overflow and uses long data types to handle rapidly growing factorial values.
